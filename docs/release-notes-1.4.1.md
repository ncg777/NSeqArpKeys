# NSeqArpKeys 1.4.1

## Compact laptop interface

- Replaces the 980 × 900 melodic editor with an 820 × 600 default layout,
  grouping related controls into columns while keeping readable text and inputs.
- Starts smaller when the desktop work area requires it. Resize with the
  bottom-right corner, down to 640 × 400 logical pixels. Horizontal and vertical
  scrolling keep every control accessible at smaller sizes.
- Preset navigation remains visible above the scrollable controls. Switching
  melodic/rhythmic modes or opening either browser keeps the chosen window size.
- Reflows both browsers to fit the compact window. Pattern Bank save, import,
  and export actions now occupy separate rows instead of overflowing the window.
- Scrolling over a slider scrolls the panel without accidentally changing values.

Playback, host parameters, and project/preset/pattern-bank formats are unchanged.
Existing 1.4.0 projects and patterns remain compatible.
