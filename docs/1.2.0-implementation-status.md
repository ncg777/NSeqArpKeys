# NSeqArpKeys 1.2.0 implementation status

This branch is work in progress toward the [complete roadmap](1.2.0-roadmap.md). The version identifiers are set to 1.2.0 for test builds; do not tag a release until the remaining work has been implemented and validated on supported hosts.

## Implemented on this branch

- Per-key subdivision (0 inherits the existing global host parameter) with simultaneous independent rates, legacy preset migration by default, saved state, and automation refresh in the editor.
- Melodic and rhythmic interpretation. Rhythmic mode maps bits 0–15 to 16 editable MIDI note numbers. Changing mode from channel 1 selects channel 10.
- Base velocity multiplied by trigger velocity and an optional cycling per-step velocity lane; cycling semitone offsets for pitch.
- Integer sequence rotation and reversal, chromatic transpose, Euclidean bit-0 generation.
- Individual pattern names; copy, paste, duplicate to next key, bounded per-key undo/redo; separate single-pattern `.nseqpattern` save/load through a file chooser.
- Populate an inclusive key range with independent copies of the source assignment, optionally transposed by key distance.
- Shared output-pitch note ownership across simultaneous trigger keys.
- 1.2.0 CMake, Projucer and generated Windows version metadata; source HTML manual, printable PDF, and README updates.

## Next work required to fulfill the roadmap

- Replace the file chooser with a searchable pattern-bank browser, with tags, favourites, auditing and shared pattern identity (linked versus independent copies).
- Define and implement a distinct range assignment model with input-channel filters, live shared pattern edits, priority/layering and set-degree transposition; make range edits a single undo transaction.
- Add rhythmic velocity bits per lane, separate accent lanes, drum-gate controls, hit probability, ratchets, swing and adjustable microtiming.
- Build a non-destructive, ordered sequence-operator chain: masks, time reversal versus bit reversal, block permutations, combination policies for unequal lengths, preview and bake.
- Add independent modulation clocks, phase and retrigger behaviour, MIDI CC mappings and assignable macros.
- Add quantized launches, one-shot and per-key latch, exclusive groups, scenes, seeded mutations, follow actions, constrained completion and performance MIDI capture/export.
- Validate DAW state and automation in VST3/AU, test actual standalone GUI and MIDI playback on Windows/macOS/Linux, and run cross-platform release packaging and PDF visual checks before release.

## Verification performed

- Standalone domain tests compile and run with g++.
- Pattern scheduler regression tests compile with JUCE audio/core sources and run locally.
- Processor and editor translation units pass C++ syntax checks against JUCE 8.0.6 headers.
- The packaged PDF was regenerated from the edited HTML and rendered to images for visual inspection.

The complete CMake plugin build could not be configured in this container because system pkg-config and Linux development headers are unavailable; the repository's GitHub Actions matrix remains the gate for full native builds.
