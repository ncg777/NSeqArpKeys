Standalone instrument + VST3 / AU plug-ins

User manual for the pattern-driven keyboard instrument.

Assign a sequence and a Forte pitch-class set to any MIDI key. Hold the key to play the pattern, or latch it while you edit. Shape note lengths with Gate and Fixed Steps, then save the complete setup as a preset.

Windows / Linux / macOSVersion 1.2.0 | September 2026

1. Get started

You can use NSeqArpKeys on its own or load a plug-in in a compatible DAW.

Install

Standalone

Extract your OS archive and run NSeqArpKeys.exe on Windows, NSeqArpKeys on Linux, or NSeqArpKeys.app on macOS. Use Options to select an audio device if needed.

Plug-in

Copy the complete NSeqArpKeys.vst3 bundle to your VST3 folder and rescan in your DAW. The macOS archive also includes NSeqArpKeys.component for Audio Units.

Keep plug-in bundles intact. VST3 folders: Windows C:\Program Files\Common Files\VST3, Linux ~/.vst3, macOS ~/Library/Audio/Plug-Ins/VST3. For Audio Units on macOS, use ~/Library/Audio/Plug-Ins/Components.

Make your first pattern

  1. Open Browse Presets, choose Single Note Pulse, and click Load. This assigns a playable example to C4 (MIDI 60).
  2. Hold C4 on the on-screen keyboard or send MIDI note 60 to the plug-in. The pattern plays while that key is held.
  3. Release C4 to stop. To keep it running while editing, turn on Latch (keep playing), trigger C4 once, and release it.
  4. Click the same key again, or use Stop Key or Stop All, to stop a latched pattern.

A melodic key needs both a nonzero Pattern step and a Forte Set. Rhythmic mode uses Drum notes instead. The Init preset is deliberately silent.

2. Work in the editor

The keyboard selects a trigger note. The controls below it edit the assignment for that key. Each of the 128 MIDI keys can have its own pattern, set, channel, octave, gate, subdivision and expression.

Change a running pattern

With Latch on, trigger and release a key, then edit its controls while listening. Most edits restart that key on the next audio block, preserving trigger velocity. Changes to tempo or Steps/QN preserve musical phase and pending note-offs.

Selected key matters. Stop Key applies to the key shown in the selected-key label. Stop All ends every currently playing pattern.

3. Patterns, pitch, and timing

Pattern values

Enter whole numbers separated by spaces. Each number is one step. Positive numbers are bit masks over ascending notes of the selected Forte set. Negative numbers select in the opposite direction from the Octave base. Zero starts no new note.

Example - four steps1 2 3 0

1 plays the first available note, 2 the next, and 3 plays both together. 0 creates a rest after the chord.

Octave moves the base position used by these bit masks. Channel sets the outgoing MIDI channel from 1 to 16. Notes outside MIDI's 0-127 range are ignored.

Gate across zero steps

A sounding step owns the zero steps that follow it, including zero steps at the end of a looping pattern. Gate is a percentage of that entire span, from the note onset to the next sounding step.

Example - a three-step span1 0 0 2

The first note has three steps available: its own step and two following zeros. At 50% Gate it sounds for 1.5 steps; at 100% it reaches the next sounding step. A zero step does not retrigger the note.

Gate ranges from 0% to 200%. Values above 100% can overlap later notes. Fixed Steps ranges from 0 to 16 in increments of 0.01. The two lengths add: note length = Fixed Steps + Gate x sounding span. For example, a three-step span with Gate 50% and Fixed Steps 0.5 lasts 2 steps. Releasing the trigger key stops the pattern immediately when Latch is off.

Tempo and meter

Pattern steps follow the DAW tempo when a host supplies one. Otherwise the instrument uses 120 BPM. One step lasts 60 / (BPM x effective Steps/QN) seconds: at 120 BPM and Steps/QN 4, a step lasts 0.125 seconds. A per-key value of 0 inherits the global setting. Meter Num is saved but does not currently change step duration or pattern length.

Rhythmic mode and variation

In rhythmic mode, bit 0 plays the first Drum note, bit 1 the second, and so on to bit 15. Pattern 5 0 triggers bits 0 and 2, then rests. Nonpositive masks are silent. The usual output channel is 10 when switching from channel 1.

Output velocity scales with incoming key velocity. Velocity values are 0-127; zero silences a step. Pitch offsets are -127 to 127 semitones. Both lanes cycle within the pattern and restart at every pattern loop. Rotate and Reverse reorder the integer steps, leaving the lanes in place.

4. Forte sets

A Forte set supplies the pitch classes from which Pattern values choose notes. Each menu match shows its Forte ID, any common name, and its pitch classes in brackets.

  1. Select the MIDI key you want to configure.
  2. Type part of an ID, a common name such as diatonic, or pitch classes in Find Set.
  3. Open Forte Set and choose a match. The selected set is shown underneath.
Example

7-35.11 - diatonic scale [0 2 4 5 7 9 11] contains seven pitch classes. With this set, 1 2 4 8 walks upward through its first four scale positions.

Choose (No set) to clear the selected key's set. A melodic pattern without a set is silent; rhythmic mode uses Drum notes independently. Changing search text only filters the menu; choose a result to change the assignment.

Live performance

Normally, a pattern runs only while its trigger note is held. Latch changes note release behavior: the first trigger keeps the pattern running, and another trigger of the same key switches it off. Turning Latch off stops patterns whose trigger keys are no longer held.

The plug-in emits generated MIDI notes and also has an internal preview sound. In a DAW, generated MIDI routing depends on the host. In standalone mode, check Options for the audio output device if you cannot hear the preview.

5. Presets

A preset captures the meter, latch setting, selected key, and all 128 key assignments. The library has six factory examples and can hold your own presets.

Browse and load

Open Browse Presets. Search names, categories, tags, and descriptions; narrow results with the Category menu or Favourites only. Select a row to inspect its details, then click Load. Loading replaces the current setup and stops any active patterns.

Where presets live: in the OS application-data folder under NSeqArpKeys/Presets (for example, %APPDATA%\NSeqArpKeys\Presets on Windows). The standalone app and plug-ins share this folder on each OS.

Individual pattern files

Save pattern and Load pattern use the separate NSeqArpKeys/Patterns folder. Whole presets embed every assignment, so they can travel without the pattern bank. Loading a pattern replaces only the selected key and restarts it if active. Other keys keep playing. Pattern loading and range copies can be undone. Undo/Redo lasts for the editor session and resets when loading a whole preset or project.

6. If something is not working

What you noticeWhat to check
No notes when a key is heldSelect the key, enter at least one nonzero Pattern value, and choose a Forte Set. Try the Single Note Pulse factory preset on C4.
The pattern stops when you release the keyThat is the default behavior. Turn on Latch before triggering the key if you want it to continue during edits.
A pattern keeps playingClick its trigger key again while Latch is on, use Stop Key for the selected key, or use Stop All.
No sound in standalone modeOpen Options and select an active audio output device. Confirm the selected key has a playable assignment.
VST3 does not appear in the DAWKeep the outer NSeqArpKeys.vst3 folder intact in the VST3 directory and rescan plug-ins in the DAW.
A preset does not appearCheck the browser's search, category, and Favourites only filters. User files must be valid .nseqpreset files in the preset folder.

Quick reference

To hear a pattern

Assign Pattern + Forte Set, then hold the trigger note. Use Latch to keep it running while you edit.

To share a setup

Save New, select the preset in the browser, then Export. Send the resulting .nseqpreset file.
