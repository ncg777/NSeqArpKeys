VST3 / AU MIDI pattern plug-ins

Turn integer sequences into melodies and chords through Forte pitch-class sets.

Each pattern integer is a binary note selector: one set bit chooses one pitch, and several set bits make a chord. Change the Forte set to remap the same sequence to a new pitch collection. Assign a different pattern and set to each MIDI trigger key.

Create more material with Sequence Operator, Rhythm Navigator, and KComplexExplorer.

Windows / Linux / macOSVersion 1.3.1 | September 2026

1. How integer patterns become notes

A short sequence of numbers becomes a melody, chords, and rests when you choose a Forte set.

In Melodic mode, each space-separated integer in Pattern is one step. The chosen Forte Set supplies pitch classes (0 = C through 11 = B); NSeqArpKeys repeats them in ascending order across octaves. The Octave control chooses the starting position, called the anchor below.

Read the magnitude of a step in binary from right to left. The rightmost bit, bit 0, selects the anchor note; bit 1 selects the next note in the expanded set; bit 2 selects the note after that. Several set bits play together. A positive number walks upward, a negative number walks downward from the same anchor, and zero starts no note.

Hear the mapping

Choose 7-35.11, the diatonic set [0 2 4 5 7 9 11] (C D E F G A B), and set Octave to 4. The anchor is C (MIDI 48), followed upward by D (50), E (52), and F (53).

2. Get started

Load NSeqArpKeys as an instrument plug-in in a compatible DAW.

Install

Plug-in

Copy the complete NSeqArpKeys.vst3 bundle to your VST3 folder and rescan in your DAW. The macOS archive also includes NSeqArpKeys.component for Audio Units.

Keep plug-in bundles intact. VST3 folders: Windows C:\Program Files\Common Files\VST3, Linux ~/.vst3, macOS ~/Library/Audio/Plug-Ins/VST3. For Audio Units on macOS, use ~/Library/Audio/Plug-Ins/Components.

Make your first pattern

  1. Open Browse Presets, choose Single Note Pulse, and click Load. This assigns a playable example to C4 (MIDI 60).
  2. Hold C4 on the on-screen keyboard or send MIDI note 60 to the plug-in. The pattern plays while that key is held.
  3. Release C4 to stop. To keep it running while editing, turn on Latch (keep playing), trigger C4 once, and release it.
  4. Click the same key again, or use Stop Key or Stop All, to stop a latched pattern.

A melodic key needs both a nonzero Pattern step and a Forte Set. Rhythmic mode uses Drum notes instead. The Init preset is deliberately silent.

Make patterns with companion apps

  • Sequence Operator (ncg777.github.io/sequence-operator/) creates and transforms integer sequences. Copy its result into a Melodic Pattern to hear those numbers as notes and chords.
  • Rhythm Navigator (ncg777.github.io/rhythm-navigator/) supplies onset patterns. Put the Sequence Operator values at those onsets and 0 at rests. For drums, use Combined sequence → Copy in its drum sequencer and paste the decimal masks into a Rhythmic Pattern. Use at most 16 lanes, set Velocity bits/lane to 1, enter Drum notes in its displayed bit order, and set Steps/QN to its displayed denominator when that is 16 or less.
  • KComplexExplorer (ncg777.github.io/KComplexExplorer/) lets you audition and compare pitch-class sets, inspect their Forte numbers and interval vectors, and generate harmonic matrices. Choose a set in Find Set / Forte Set; different trigger keys can use different sets. Its padded suffix .09 appears as .9 in NSeqArpKeys.

Use KComplexExplorer for the pitch collection, Sequence Operator for the note-mask stream, and Rhythm Navigator for its timing; then trigger the finished pattern from a MIDI key in NSeqArpKeys.

Change a running pattern

With Latch on, trigger and release a key, then edit its controls while listening. Most edits restart that key on the next audio block, preserving trigger velocity. Changes to tempo or Steps/QN preserve musical phase and pending note-offs.

Selected key matters. Stop Key applies to the key shown in the selected-key label. Stop All ends every currently playing pattern.

4. Patterns, pitch, and timing

Pattern values

Enter whole numbers separated by spaces. Each number is one step. Positive numbers are bit masks over ascending notes of the selected Forte set. Negative numbers use the bits of their absolute value in the opposite direction from the Octave anchor. The least significant bit selects the anchor in both directions. Zero starts no new note.

Example - four steps1 2 3 0

1 plays the first available note, 2 the next, and 3 plays both together. 0 creates a rest after the chord.

Octave moves the base position used by these bit masks. Channel sets the outgoing MIDI channel from 1 to 16. Notes outside MIDI's 0-127 range are ignored.

Gate across zero steps

A sounding step owns the zero steps that follow it, including zero steps at the end of a looping pattern. Gate is a percentage of that entire span, from the note onset to the next sounding step.

Example - a three-step span1 0 0 2

The first note has three steps available: its own step and two following zeros. At 50% Gate it sounds for 1.5 steps; at 100% it reaches the next sounding step. A zero step does not retrigger the note.

Gate ranges from 0% to 200%. Values above 100% can overlap later notes. Fixed Steps ranges from 0 to 16 in increments of 0.01. The two lengths add: note length = Fixed Steps + Gate x sounding span. For example, a three-step span with Gate 50% and Fixed Steps 0.5 lasts 2 steps. Releasing the trigger key stops the pattern immediately when Latch is off.

Tempo and meter

Pattern steps follow the DAW tempo when a host supplies one. Otherwise the instrument uses 120 BPM. One step lasts 60 / (BPM x effective Steps/QN) seconds: at 120 BPM and Steps/QN 4, a step lasts 0.125 seconds. A per-key value of 0 inherits the global setting. Meter Num is saved but does not currently change step duration or pattern length.

Rhythmic mode and variation

Rhythmic mode needs no Forte set. Enter 1-16 Drum notes; this sets the active lane count. With one velocity bit for each lane, bit 0 plays the first pitch, bit 1 the second, and so on. Try 1 0 0 0 2 0 0 0 for notes 36 and 38 with the default map. Set Channel to match the receiving instrument; changing mode preserves it.

Velocity bits/lane is one number from 1-7, shared by every active drum lane as in GateRunner. Lane 1 occupies the least significant bits of a positive decimal step mask; each later lane uses the next group of bits. A lane value of zero rests, while nonzero values scale from quiet to velocity 127. For example, two lanes with two bits each decode step 9 as level 1/3 on lane 1 and 2/3 on lane 2. Positive masks support all 16 lanes at seven bits each (up to 112 bits). Legacy signed 32-bit masks remain accepted. Base velocity and incoming key velocity further scale the result. Rotate and Reverse reorder the integer steps.

5. Forte sets

A Forte set supplies the pitch classes from which Pattern values choose notes. Each menu match shows its Forte ID, any common name, and its pitch classes in brackets. The number before the dot identifies the set class; the suffix .0 through .11 transposes its listed pitch classes upward by that many semitones modulo 12. The interval vector stays the same under transposition. The appendix gives every base set and the rule for reading its transpositions.

  1. Select the MIDI key you want to configure.
  2. Type part of an ID, a common name such as diatonic, or pitch classes in Find Set.
  3. Open Forte Set and choose a match. The selected set is shown underneath.
Example

Base 7-35.0 is [0 1 3 5 6 8 10]. Adding 11 semitones modulo 12 gives 7-35.11 - diatonic scale [0 2 4 5 7 9 11]. With this set, 1 2 4 8 walks upward through C, D, E, F at the selected Octave anchor.

Choose (No set) to clear the selected key's set. A melodic pattern without a set is silent; rhythmic mode uses Drum notes independently. Changing search text only filters the menu; choose a result to change the assignment.

Live performance

Normally, a pattern runs only while its trigger note is held. Latch changes note release behavior: the first trigger keeps the pattern running, and another trigger of the same key switches it off. Turning Latch off stops patterns whose trigger keys are no longer held.

Turn off Preview sound to silence the built-in tones while MIDI continues. This setting is saved with the setup. Route the plug-in's MIDI output to another instrument in your DAW and match Channel to the receiving instrument. MIDI routing depends on the host.

6. Presets

A preset captures the meter, latch setting, selected key, and all 128 key assignments. The library has six factory examples and can hold your own presets.

Browse and load

Open Browse Presets. Search names, categories, tags, and descriptions; narrow results with the Category menu or Favourites only. Select a row to inspect its details, then click Load. Loading replaces the current setup and stops any active patterns.

Pattern files and whole-bank transfer

Save pattern and Load pattern use the separate NSeqArpKeys/Patterns folder. Pattern Bank searches names and tags, filters favourites, edits colour and details, auditions a selected pattern, and assigns it as an independent copy or shared link. Import bank and Export bank transfer all bank entries in one .nseqbank XML file. Import updates local entries with matching IDs, adds new entries, and retains other local entries. An entry without an ID receives one on import. Export includes all entries even when a search or favourites filter is active. Linked keys follow edits to any member; Make independent breaks the link on the selected key. Duplicate and range assignment always make independent copies. Whole presets embed shared definitions and key assignments, so they reopen without the local bank. Loading one pattern affects only the selected key. Undo/Redo lasts for the editor session and resets when loading a whole preset or project.

Appendix A. Forte pitch classes and interval vectors

This table lists all 352 base IDs in NSeqArpKeys's Forte catalogue, including the empty set. Pitch classes use C = 0, C#/D♭ = 1, D = 2, D#/E♭ = 3, E = 4, F = 5, F#/G♭ = 6, G = 7, G#/A♭ = 8, A = 9, A#/B♭ = 10, and B = 11. The displayed pitch classes belong to the .0 form of each ID.

For any other suffix .n, add n to each listed pitch class modulo 12, then sort the results. For example, 7-35.0 is [0 1 3 5 6 8 10]; 7-35.11 is [0 2 4 5 7 9 11]. Symmetric sets can have fewer than 12 distinct transpositions, so the selector only shows distinct forms. The empty set supplies no melodic notes.

The interval vector <1 2 3 4 5 6> counts unordered pitch-class pairs at each interval class in semitones, folding intervals larger than six back toward zero. For instance, [0 4 7] has one pair each at interval classes 3, 4, and 5, so its vector is <0 0 1 1 1 0>. Transposition leaves the vector unchanged.
